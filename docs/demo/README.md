## 画面与来源

开场是为演示制作的仿 VS Code 界面，使用 CodeMirror 显示[公开示例](sample.md)；后续场景使用本项目真实编辑器的浏览器预览。示例包含多级标题、引用、任务清单、表格、LaTeX、Mermaid、有序列表和代码块，不含个人信息。

画面直接输出为 1920 × 1284 的高 DPI 无损 PNG，再编码成 50 fps GIF，没有 JPEG 中间帧。鼠标采用常规尺寸的箭头与文本指针；移动与滚动使用缓入缓出的连续轨迹，选中文字使用实际鼠标拖选。录制时将原生输入光标设为稳定显示，避免截图采样放大闪烁；该设置仅作用于演示页面。输入约每字 0.08–0.1 秒，重要结果保留阅读停顿。这是经过编排的功能演示，不是性能计时。

此前写入的正文、求和公式和时序图在后续操作中始终保留。各阶段通过实际大纲点击和连续滚动衔接；片尾淡出到与片头相同的背景，再自然循环。最终时长、文件哈希和阶段检查点见 `manifest.json`。旧的独立 GIF 保留为历史素材，README 不再引用。

## 复现与审阅

```powershell
npm run dev -- --port 4192 --strictPort
# 另一个终端，保持开发服务器运行：
node scripts/capture-continuous-demo.mjs
node scripts/encode-continuous-demo.mjs
```

原始帧与 GIF / MP4 审阅稿位于本地 `artifacts/demos/review-v6/`，不纳入 Git。`capture.json` 保留逐帧时间、滚动位置与连续文档检查点；`scripts/demo.html` 和录制脚本仅用于文档制作，不修改扩展运行时。

该连续演示稿已于 2026-09-27 获用户确认，用于 0.2.7 的商店说明。README 的动图链接固定到资产提交；发布前核对公开下载哈希。商店与安装验证记录保存在本地 artifacts/marketplace/verification-0.2.7.json，以实际完成状态为准。
